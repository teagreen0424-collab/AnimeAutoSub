## 1. 语法风格与人称场景映射规则

### 1.1 `해라체` (基本阶/平叙体) 语法映射
- **语法特征**: `해라체`（Haera-che）属于非敬语（반말），多用于长辈对晚辈、平辈极其亲近之交、书面独白、内心旁白及日漫/韩漫主角的动作叙述。
- **词尾识别与中文语义映射**:
  - **平叙形 (`-다 / -ㄴ다 / -는다`)**: 映射为中文中性/断定陈述，如 `간단하다` -> "很简单"、`간다` -> "走了"。**严禁带入敬语标记（如"您"、"请问"）**。
  - **疑问形 (`-냐 / -니`)**: 映射为平辈直白发问，如 `뭐 하냐?` -> "干嘛呢？" / "在做什么？"。
  - **命令形 (`-라 / -아라 / -어라`)**: 映射为果断祈使/命令，如 `빨리 와라` -> "快点过来！"（严禁翻成"请快点来"）。
  - **共动形 (`-자`)**: 映射为提议，如 `같이 가자` -> "一起走吧"。

### 1.2 `오빠` (Oppa) 场景感知分流规则
- **场景 A: 亲属血缘场景** (家庭生活、兄妹称呼):
  - 判定依据: 上下文中出现父母、家庭关系词，或人物身份确立为兄妹。
  - 强制映射: **"哥哥"**。
- **场景 B: 恋爱/情侣/暧昧/社交场景** (年轻男女日常、恋爱动漫):
  - 判定依据: 亲密男女互动、非血缘关系、撒娇或亲昵语气。
  - 推荐映射: **"欧巴"** 或 **在对白中意译直呼人名/省略**。
  - 严禁行为: 在恋爱亲昵场景中直白生硬地翻译为"血缘哥哥"，导致读者产生伦理误解。

## 2. 韩语专用助词体系 (10 类核心助词表)

在进行 ASR 文本修复、分词断句以及 OCR 聚合时，必须根据以下 10 类助词的音变规律进行边界判定：

| 分类 | 助词形态 (有收音/无收音) | 语法功能 | 边界规则 |
| :--- | :--- | :--- | :--- |
| **1. 主格助词** | `이 / 가` | 标示句子主语 | 严禁与前实体断开成独立词 |
| **2. 宾格助词** | `을 / 를` | 标示直接宾语 | 紧贴体词词尾 |
| **3. 属格助词** | `의` | 领属关系 ("的") | 保持粘连 |
| **4. 话题/辅助** | `은 / 는` | 标示对比或主题 | 粘连 |
| **5. 与格/处所** | `에 / 에게 / 한테` | 标示到达点、时间或对象 | 粘连 |
| **6. 呼格助词** | `아 / 야` | 用于称呼非敬语对象 | 紧贴人名后 |
| **7. 伴随/共同** | `과 / 와`, `랑 /이랑`, `하고`| 标示共同行动 ("和/与") | 紧贴前词 |
| **8. 造格/工具** | `으로 / 로` | 标示手段、方向或资格 | 按是否有收音选择形态 |
| **9. 比较助词** | `보다` | 标示比较基准 ("比...") | 紧贴比较对象 |
| **10. 范围助词**| `부터`, `까지` | 标示起点与终点 ("从...到...")| 保持紧凑 |

## 3. 韩语硬字幕 OCR 提取分支规范

1. **NFKC 文本归一化 (Unicode Normalization)**:
   - 提取的 Unicode 音节块（Hangul Syllables: `U+AC00 ~ U+D7A3`）必须统一走 `unicodedata.normalize('NFKC', text)`，将兼容韩语字母（Jamo: `U+3131 ~ U+318E`）与半角假名规范化为标准音节。
2. **字符度量与独立锚定 (Box Metric Tuning)**:
   - 韩文字符为典型的“初声+中声+终声”方块组合，宽高比接近 1:1，但单行密度常高于汉字。
   - 检测框膨胀系数：水平方向 `unclip_ratio = 1.6`（相比日语 1.5 略宽），防止音节初声笔画被裁剪。
3. **无空格断行合并**:
   - 针对动漫画硬字幕常紧凑排版省略空格的现状，聚合同一行连续文本，利用助词表与词尾识别句法边界。

## 4. ASR 空格容错兜底算法 (Post-ASR Space Restoration)

### 4.1 问题病态
Whisper 等声学模型在韩语音频转写时，易受口语停顿影响产生两种错误：
1. **助词悬挂孤立**: 如 `책 을` (书 + 宾格)，被拆分成两个 token，导致机器翻译时将 `을` 误判为标点或错词。
2. **体词助词与谓词黏连**: 如 `집에갔다` 连写无空格。

### 4.2 兜底修复算法伪代码 (Regex + State Machine)

```python
import re

# 10 类常见助词集合（单音节与双音节）
PARTICLES_1 = r'(?:이|가|을|를|의|은|는|에|로|와|과|도|야|아)'
PARTICLES_2 = r'(?:에게|한테|으로|이랑|하고|보다|부터|까지)'

def repair_korean_spacing(text: str) -> str:
    """
    韩语 ASR 助词悬挂修复算法：
    将错误悬挂为空格孤立的助词重新粘回前一个体词词尾
    """
    # 模式 1: 体词 + 空格 + 助词 -> 体词 + 助词
    # 例如: "사람 이" -> "사람이", "친구 를" -> "认구를"
    pattern_hang = rf'([가-힣]+)\s+({PARTICLES_2}|{PARTICLES_1})(?=\s|[.,!?]|$)'
    text = re.sub(pattern_hang, r'\1\2', text)
    
    # 模式 2: 消除连续重复空格
    text = re.sub(r'\s{2,}', ' ', text)
    
    return text.strip()
```

此算法在 G1b 韩语链路中作为 ASR 输出的确定性前置清洗器，断言进入 LLM 翻译阶段前 100% 修复助词孤立缺陷。
