## 0. 日文链路冻结基线 (Baseline Freeze)

从 2026-11-01 起，日文硬字幕与日文语音链路**正式结项封版**。后续严禁对日文链路做任何算法改动，只允许修 bug 与加测试。之后所有讨论与报告**不得再引用任何旧数字**，统一以本节冻结基线为准：

### 0.1 生产性能基线
- **日文硬字幕链路**: 全片 69 分钟素材 $\to$ **30.79 分钟**完成（2.25x 实时速度）；
  - OCR 稳态调用耗时: **160 ms / 次**（`cudnn_conv_algo_search = "HEURISTIC"` 稳定态）；
  - 翻译单句耗时: **1.6 s / 句**（Sakura-14B via Ollama，复用 TCP Session）；
- **日文语音链路**: 21 分钟素材 $\to$ **10.9 分钟**完成（Demucs + faster-whisper large-v3）。

### 0.2 质量指标基线
- **OCR 识别质量**:
  - 合成素材 CER: **2.6%**（双行字幕）；
  - 真实母片素材 CER: **13% ~ 15%**（P2 稳定平原区中点帧提取）；
- **翻译质量 (60 句真值审计)**:
  - 严格全量口径: 可用率 **83.3%**（5分完美率，纯严格无瑕疵）；
  - 实用语义口径: 可用率 **91.7%**（5+4分可用率，55/60 句语义通顺准确可用）；
  - 不可用率: **6.67%**（4/60 句，全部为 Z4 归档的 OCR 前端不可救损毁样本）；
  - 回归率: **0 项**（旧对新错数量为 0）。

### 0.3 已证伪、严禁再试技术路径 (Permanently Rejected)
以下方向已在前期验证中被严格证伪，**绝对不许重试**：
1. 图像预处理全家桶（灰度化、CLAHE、Otsu 二值化、掩膜膨胀等）；
2. `japan` 专用识别模型（`japan_PP-OCRv4_rec_mobile`，CER 27.44%，较默认模型暴跌 10+ 个百分点）；
3. 时序多帧投票（Majority Voting，同素材帧间误差同向，导致负收益）；
4. 检测 2x 上采样与 Y 轴重聚类（长集退化 -3.15pt，产生背景碎屑噪点）；
5. `manga-ocr`（吞吐过慢且无法胜任带描边硬字幕）；
6. cuDNN `EXHAUSTIVE` 算法搜索（导致 88% 墙钟时间浪费在 autotune 停顿）；
7. `localhost` 请求（Windows IPv6 `[::1]` 导致 2000ms TCP SYN 重传超时，必须强制 `127.0.0.1`）；
8. 无 Session 的短连接（每次请求新建 TCP 握手，必须使用连接池）。

## 2. OCR 冻结与基线定型 (OCR Freeze)

- **定型水平**：15 帧短集 **15.49%**、12 帧长集 **13.25%**（均为 P2 稳定平原区中点帧 + 默认 PP-OCRv6 multi 多语种模型）。
- **已知限制**：
  - **复杂背景漏检**：高对比度人物服装纹理等复杂背景会导致文字上下行连通被 det 误判为超大噪点块并丢弃，整行漏检（短集帧 010 已严格定位）。
  - **双行合并**：合并正确率约 5/6，长句偶发上下行顺序错乱。
  - **乱码尾巴**：尾部偶发 ASCII 碎片乱码（如 `TYAGOAL` 类），后续需配合 N5 拒识机制挡在翻译流水线之前。
- **已证伪、严禁再试方向 (REJECTED)**：
  - 图像预处理（灰度、CLAHE、Otsu 二值化、白字掩膜、上采样）；
  - `japan` 专用模型（`japan_PP-OCRv4_rec_mobile` 实测 CER 27.44%，较默认模型暴跌 10+ 个百分点）；
  - 时序多数投票（Majority Voting，同素材帧间误差同向，导致负收益）；
  - det 2x 上采样 + Y 轴聚类（长集退化 -3.15pt，产生背景碎屑噪点）；
  - `manga-ocr`（吞吐过慢且无法胜任带描边硬字幕）。
- **重启条件 (Unfreeze Conditions)**：
  - 只有当“换检测模型”或“引入 VLM OCR”这类结构性方案出现时才允许重新开启；
  - 且必须在同一 27 帧基准上实测显著优于 13%–15.5% 方允许替换。

## 5. 素材与母片绝对安全纪律 (Material Safety Discipline)

- **核心纪律**: `input/` 与 `ocr_input/` 为唯一母片/原始素材输入源，**严禁任何自动化脚本、测试用例或排查命令对其执行 `Remove-Item`、`unlink`、`os.remove`、`shutil.rmtree` 或跨目录覆盖**。
